Задание

Одно на всех: свой цифровой рудник

Треков и номинаций нет. Рудник придумываете вы: карьер или шахта, своя техника, свои процессы, свои Модули. Глубина важнее количества: один Модуль, сделанный хорошо и обоснованно, ценнее пяти заглушек. Пример рудника в платформе — только образец того, как всё устроено; оценивается то, что сделали вы.

Как участвовать

Три шага до финала

  1. 1

    Регистрация

    Заполните форму. Каждый участник получит приглашение в приватный репозиторий команды с полной копией OpenEgiz. Сохраните ссылку «Изменить ответ» — через неё изменяется состав команды.

  2. 2

    Стройте на OpenEgiz

    Двойники — в Eclipse Ditto, данные передаются через платформу, интерфейс получает их из неё. Изменять можно любые части, включая ядро. Допускаются любые инструменты, в том числе ИИ.

  3. 3

    Сдайте до 25 октября

    В ветке main: README.md, SUBMISSION.md и presentation.pdf. В 23:59 репозиторий замораживается и становится публичным.

Главное техническое требование. Решение должно запускаться по README без ручного вмешательства в Окружении судьи — чистой виртуальной машине Ubuntu с Docker. Проверьте инструкцию в таком же окружении до Заморозки.

Как оценивают

Судят модели ИИ, а не люди

Несколько моделей ИИ, в том числе OpenAI и Anthropic. Рубрика — в Положении; контрольная сумма пайплайна — до Заморозки; промпты Судей, код пайплайна, отчёты и оценки по каждому Решению — после Отборочного этапа.

Сборщик

Запускает каждое Решение по README в чистой виртуальной машине и составляет Отчёт сборки

Судьи

Независимо выставляют баллы по Рубрике: изучают код, презентацию и интерфейс Решения
