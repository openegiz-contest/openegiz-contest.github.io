The task

One task for all: a digital mine of its own for each Team

There were no tracks or categories. Each Team started with its Concept, the first section of SUBMISSION.md, written before the code: which enterprise or which part of it, who uses the twin, which decision it helps to make, and why this choice. Given the same task, AI agents build the same mine; different twins come from different people. The Example Mine in the platform served only as a sample of how everything is structured; what was evaluated was what the Team built.

How the contest ran

Three steps to the Final

  1. 1

    Registration

    Teams registered through a form. Each Participant received an invitation to a private Team Repository with a full copy of OpenEgiz.

  2. 2

    Building on OpenEgiz

    The Concept first, then the code. Twins live in Eclipse Ditto, data flows through the platform, and the interface reads it from the platform. Any part could be changed, including the core. Any tools were allowed, including AI.

  3. 3

    Submission by 25 October

    On the main branch: README.md, SUBMISSION.md and presentation.pdf. At 23:59 the repositories were frozen and made public.

The key technical requirement. A Submission had to start by following the README, with no manual intervention, in the Judge Environment: a clean Ubuntu virtual machine with Docker.

How it was judged

Judged by AI models, not people

Several AI models, including models from OpenAI and Anthropic. The Rubric is part of the Rules. The pipeline checksum was published on 27 October, after the Freeze, later than clause 8.5 required (Discussion #3). The Judges’ prompts, the pipeline code, the reports and the scores were published after the Qualifying Round.

Builder

Ran each Submission following its README in a clean virtual machine and wrote a Build Report

Judges

Scored independently against the Rubric, examining the Concept, the code, the presentation and the interface of the Submission

Final

The reference point under the Rules is the Default Solution: what AI agents build from the Template given one sentence, with no Concept and no edits. The Default Solution has not been published; the Judges assigned levels using the level descriptions of the Rubric.

A Submission that failed to start by following its README or was not built on OpenEgiz received no more than 40 points and could not become the Winner. Details are in the Rules.
