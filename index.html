The task

One task for all: your own digital mine

There are no tracks or categories. You design the mine: open pit or underground, your own equipment, your own processes, your own Modules. Depth matters more than quantity: one Module built well and justified is worth more than five stubs. The Example Mine in the platform is only a sample of how everything is structured; what is evaluated is what you build.

How to take part

Three steps to the Final

  1. 1

    Registration

    Fill in the form. Each participant receives an invitation to a private team repository with a full copy of OpenEgiz. Keep the “Edit response” link: use it to change the team’s membership.

  2. 2

    Build on OpenEgiz

    Twins live in Eclipse Ditto, data flows through the platform, and the interface reads it from the platform. You may change any part, including the core. Any tools are allowed, including AI.

  3. 3

    Submit by 25 October

    On the main branch: README.md, SUBMISSION.md and presentation.pdf. At 23:59 the repository is frozen and made public.

The key technical requirement. The Submission must start by following the README, with no manual intervention, in the Judge Environment: a clean Ubuntu virtual machine with Docker. Test your instructions in the same environment before the Freeze.

How it is judged

Judged by AI models, not people

Several AI models, including models from OpenAI and Anthropic. The Rubric, the Judges’ prompts and the pipeline code are published before the Freeze; the reports and scores for each Submission, after the Qualifying Round.

Builder

Runs each Submission following its README in a clean virtual machine and writes a Build Report

Judges

Score independently against the Rubric, examining the code, the presentation and the interface of the Submission

Final

The Judges discuss the ten best Submissions live and decide first to third places

Domain Fidelity25
Launch and Operation per README20
Mine Visualization20
Mine Map Coverage15
Code and Architecture Quality10
Presentation10

A Submission that fails to start by following its README or is not built on OpenEgiz receives no more than 40 points and cannot become the Winner. Details are in the Rules.
